HOTEL CANCELLATION PREDICTION - HOW TO RUN (Windows)
====================================================

1. Unzip this whole folder (right-click the zip > Extract All).
   Do NOT run it from inside the zip.

2. Double-click  run.bat
   - First time only: it installs everything (needs internet, a few minutes).
   - Two black windows open. Keep them open while you use the project.
   - Your browser opens the login page by itself.

3. Use the website
   CUSTOMER : click "Create an account", register, make predictions,
              see your own history in "My History".
   ADMIN    : open  http://127.0.0.1:5500/frontend/admin_login.html
              email    admin@hotel.com
              password Admin@123      (change it - see README.MD)

To stop: close the two black windows.

If it does not open:
 - "Python was not found": install Python 3.12+ from python.org and tick
   "Add python.exe to PATH", then double-click run.bat again.
 - Page says "Cannot reach the server": the backend window shows an error.
   Read it, or send me a screenshot of that window.

Manual way (only if run.bat does not work), in PowerShell inside this folder:
   py -m venv venv
   .\venv\Scripts\python -m pip install -r requirements.txt
   cd backend
   ..\venv\Scripts\python app.py            (window 1)
   cd ..
   .\venv\Scripts\python -m http.server 5500 --bind 127.0.0.1   (window 2)
Then open http://127.0.0.1:5500/frontend/login.html
